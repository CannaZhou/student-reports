# 信息科技 · 分课课堂检测系统（三至六年级）

零依赖 Node 小系统：每个年级/每课一套在线检测卷，学生选名字登录作答，**自动批改、自动记录每一课成绩**；第 5 题等综合题支持**流程图在线填空**（结构画好、空格里从词库选词，降低畏难、便于自动判分）。

- 端口 **7000**，数据存 `app/data/`（名单 / 成绩 / 会话密钥，已 gitignore）
- 局域网内电脑、平板、手机浏览器直接打开 `http://本机IP:7000`（同 Wi-Fi，防火墙放行 7000）
- 计分：**每题整题答对得 1 积分**（多空填空 / 流程图须整题全对才 +1），一课满分 = 题数；不展示分值数字，只标难度星（★简单 ★★中等 ★★★偏难）。
- 架构预留公网：以后可挂到域名 + 隧道（本版未启用）

## 启动 / 停止

双击根目录 **`启动课堂检测.bat`**（会另开一个保持运行的窗口，打印访问网址）；停止用 **`停止课堂检测.bat`**。

不带界面启动：

```bash
cd app
node server.js
```

首次运行自动初始化教师默认密码 `123456`（进教师端后请修改）。

## 三个入口

| 页面 | 地址 | 用途 |
|---|---|---|
| 学生答题 | `http://localhost:7000/quiz`（首页“开始答题”） | 选名字登录 → 选年级/单元/课 → 在线作答（填空/流程图都带候选词点选）→ 交卷即批改并记录成绩 |
| 我的积分 | `/scores` | 学生查自己各课最高积分/最近/历次 |
| 教师管理 | `/teacher` | 导入名单、看各课完成率、看某课每个学生的最高积分/次数、重置某生 |

## 内容与名单怎么来

- **题目**：写在 `tools/seed.js` 里（当前示范：六年级上册·算法实现·第1课《算法与问题解决》，5 题、每题 1 积分：
  判断★ / 单选★ / 填空★★（每空给候选词点选）/ 多选★★ / **流程图填空★★★**）。改题/加课 → 编辑 `seed.js` → `node tools/seed.js`。逐课内容放 `content.json`（年级→册→单元→课）。
- **名单**：教师端“学生名单”→ 文本框粘贴，每行 `班级，姓名`（如 `2023级6班，张三` 自动识别年级），点“追加”或“清空并重新导入”。也可用示例账号测试。
- 目录只有放课的内容才有年级页签；内容未准备到的年级显示“准备中”。

## 流程图填空数据怎么写（第 5 题那类）

在 `seed.js` 的题目里加 `type: 'flow'`：

```js
{
  id: '…-q5', type: 'flow', points: 30, level: 3,
  q: '题干…',
  flow: {
    canvas: { w: 860, h: 1050 },
    nodes: [ { id: 'nStart', shape: 'term',    x:150, y:55,  w:160, h:46,  text: '开始' },
             { id: 'nA',    shape: 'diamond',  x:150, y:355, w:200, h:150, text: '{q5b2}' }, …],
    edges: [ { from: 'nStart', to: 'nA', pts: [[150,78],[150,121]], label: '' } ],
    blanks: [ { key: 'q5b2', mode: 'pick', pts: 5, show: '是 A 吗？', words: ['是 A 吗？', …干扰项], accepts: ['是 A 吗？','是 a 吗？'], expl: '…' } ]
  }
}
```

- 节点 `x,y` 是**中心**坐标；`shape` 按教材规范绘制：`term`(起止=圆角矩形) / `proc`(处理=直角矩形) / `io`(输入输出=平行四边形) / `diamond`(判断=菱形)；连线只走水平/垂直，转弯处自动补直角。`text` 里用 `{key}` 表示该处是一个空。
- `blanks.mode:'pick'` = 候选词点选（服务端只给学生发 `words` 候选词，不发答案）。流程图的空会以整题判分（**全部空对**这题才 +1 积分），但交卷后会逐空回显对错与应填内容。
- 普通**填空题**也能用同样的“候选词点选”降难度：在 `fill` 题的 `blanks` 里写 `mode:'pick'` + `words:[正确项,…干扰词]`（首项建议放正确项；每个空给 3 个左右即可）；不写 words 的填空保持手写输入。
- 判分器与填空共用 `core/grade.js` 的 `gradeBlanks`（`fill` 多空与 `flow` 同逻辑）。

## 冒烟测试

先启动服务，再：

```bash
node tools/smoke.js
```

会验证：教师登录 → 名单 → 取卷不泄露答案 → 全对 5/5 积分 → 部分错 3/5 积分（多选错 1 项、流程错 1 空都整题不得分，且流程第 2 空判错并回显应填内容）→ 成绩 best/last 回读 → 教师按课成绩 → 清理测试成绩。

## 常见问题

- **手机/平板打不开**：确认同一 Wi-Fi；Windows 防火墙放行 7000；地址用 `ipconfig` 查到的本机 IP。
- **改了前端样式不生效**：页面已禁用缓存，强刷（Ctrl+F5）即可。
- **想改端口**：`set PORT=8000` 后再 `node server.js`，或编辑 `app/config.js` 的 `port`。
- **名单被覆盖风险**：用“追加”；“清空并重新导入”前会二次确认。
